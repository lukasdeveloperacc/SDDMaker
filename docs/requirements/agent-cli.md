# 에이전트 연동

> 상태: 예정 ([changes/001-mvp.md](../changes/001-mvp.md))

## 목적

API 키 없이, SDDMaker가 실행되는 환경의 `claude` CLI와 `codex` CLI에 구독 계정으로 로그인해 인터뷰와 문서 생성을 실행한다. 호스트 직접 실행과 컨테이너 실행 모두 전용 로그인 저장소를 사용한다. 로그인도 앱 화면에서 시작할 수 있다. CLI별 실제 명령·출력 형식은 [1-SYSTEM-ARCHITECTURE.md](../1-SYSTEM-ARCHITECTURE.md#외부-연동-에이전트-cli).

## 동작

### 실행

- 인터뷰와 각 문서 단계에서 `claude` 또는 `codex`를 고른다.
- 서버가 고른 CLI를 자식 프로세스로 실행하고 출력을 SSE로 브라우저에 흘린다.
  - Claude는 글자 조각이 오는 대로 보여 준다.
  - Codex는 조각을 주지 않으므로 끝날 때까지 "생성 중"과 경과 시간을 보여 주고, 끝나면 전체 본문을 한 번에 보여 준다.
- 인터뷰처럼 여러 턴이 필요한 단계는 세션 ID로 이어 간다. 세션은 단계 안에서만 쓴다.
- 실행 중에는 **취소** 버튼을 보여 준다. 취소하면 자식 프로세스를 종료하고 결과를 저장하지 않는다.
- 인터뷰·문서 생성은 한 번에 최대 10분 실행한다. 초과하면 프로세스 그룹을 종료하고 `agent_failed`와 `응답 시간이 초과되었습니다`를 전달한다. 부분 결과는 저장하지 않는다.

### 로그인 상태

- `/settings/agents`의 연결 화면에 CLI별 상태(미설치 / 미로그인 / 구독 아닌 로그인 / 로그인됨)를 보여 준다. 작업 화면에는 로그인 UI 없이 에이전트 Select만 둔다.
- 실행 직전에도 상태를 확인한다. 로그인됨이 아니면 실행하지 않고 연결 화면으로 이동할 링크를 보여 준다.
- 로그인된 계정에는 **연결 해제**를 제공한다. 공식 CLI 로그아웃으로 SDDMaker 전용 인증만 해제하고 상태를 다시 읽는다. 프로젝트와 문서는 보존한다. 진행 중 로그인 취소와 계정 로그아웃은 별도 동작이며, 같은 CLI의 인증 작업은 동시에 실행하지 않는다.

### 앱에서 로그인

상단 메뉴의 **연결**에서 **간편 로그인 / 터미널** 탭을 고른다. 기본은 간편 로그인이다. 인증 중에는 탭 전환을 막고 취소 또는 완료 후 전환할 수 있다. 필요한 인증 도움말만 툴팁으로 둔다.

화면은 **AI 에이전트**(Claude Code·Codex)와 **GitHub** 섹션으로 나뉜다. 로그인 방식 탭은 화면 위쪽에 하나만 두고 두 섹션에 함께 적용한다. 상단 바는 로고 → 메뉴(**프로젝트**, **연결**) → 사용량 순서이며, 현재 메뉴는 `aria-current="page"`와 밑줄로 표시한다 ([changes/011-connections-page.md](../changes/011-connections-page.md)).

- **간편 로그인**: 공식 CLI의 인증 URL을 버튼으로 연다. Claude는 브라우저에서 받은 코드를 입력하면 같은 CLI 세션에 전달한다. Codex는 기기 코드 복사와 인증 페이지 열기를 제공하며, 코드는 OpenAI 페이지에 입력한다.
- **터미널**: 서버가 고정된 공식 로그인 명령을 실제 PTY에서 실행하고 브라우저의 xterm.js에 연결한다. 키 입력·붙여넣기·방향키·Ctrl+C와 ANSI 출력·커서 이동·터미널 크기 변경을 전달한다. URL은 터미널에서 클릭해 브라우저로 연다.

Codex 기기 로그인이 차단되면 ChatGPT 보안 설정에서 기기 코드 로그인을 허용하고 다시 연결한다. 로그인 명령이 끝나면 상태를 다시 확인한다. 성공하면 인증 UI를 닫고, 실패하면 짧은 오류와 재시도를 표시한다. 다른 창이나 이전 연결이 진행 중이면 **연결 재시작**으로 기존 프로세스 종료를 기다린 뒤 다시 연결한다. 종료 실패 시 새 로그인을 시작하지 않는다.

두 CLI 모두 앱 전용 저장소를 쓰므로, 호스트 터미널에서 이미 로그인해 있어도 SDDMaker에서 한 번 더 로그인해야 한다. 호스트 로그인 파일을 공유하지 않으며 컨테이너 안에서 독립적으로 인증할 수 있다. 인증 URL은 사용자의 브라우저에서 열고, Claude의 반환 코드는 앱을 통해 같은 컨테이너의 CLI로 전달한다. 터미널 직접 로그인은 컨테이너 안에서 실행한다.

### 사용량

[changes/010-agent-usage.md](../changes/010-agent-usage.md), [changes/013-live-usage.md](../changes/013-live-usage.md)

- 넓은 화면에서는 상단 바 오른쪽 끝에 구독으로 로그인된 에이전트마다 한 줄로 보여 준다: 이름, 한도 막대, `45% 2h 12m`(5시간 한도의 사용 비율·초기화까지 남은 시간), `· 38% 5d 7h`(주간 한도). 로그인되지 않은 에이전트는 표시하지 않는다.
- 막대 길이는 5시간 한도, 5시간 한도가 없으면 주간 한도의 사용 비율이다.
- 막대 색은 초기화 시각이 지나지 않은 두 한도 중 높은 비율을 따른다. 80% 이상이면 경고색, 100%면 위험색이다. 색만으로 구분하지 않고 비율 숫자를 항상 함께 보여 준다.
- 값이 없거나 초기화 시각이 지났으면 `—`를 보여 준다. 탭이 보이는 동안 1분마다 다시 읽고 남은 시간도 다시 계산한다. 다른 탭에서 돌아오면 바로 읽는다. 툴팁에 마지막으로 읽은 시각을 보여 준다.
- 1024px 이하 폭에서는 사용량 줄이 브랜드·메뉴 아래 별도 줄로 내려간다. 600px 이하에서는 아래의 축약 표시로 바뀐다.
- 600px 이하 폭에서는 막대를 숨기고 `Claude 45% · Codex 1%`처럼 한 값만 보여 준다. 값은 막대 색과 같은 규칙으로 초기화 시각이 지나지 않은 두 한도 중 높은 비율이다. 대비를 위해 경고는 짙은 주황 보통 굵기, 위험은 짙은 주황 굵게 보여 준다.
- **Claude**: 읽을 때마다 공식 CLI의 `claude -p /usage`에서 한도를 읽는다. 모델을 실행하지 않는다(토큰 0). 읽지 못하면 실행 출력의 `rate_limit_event`로 받아 둔 마지막 값을 쓴다.
- **Codex**: 읽을 때마다 공식 `codex app-server`에서 한도를 읽는다. 모델을 실행하지 않는다.
- 화면을 열 때, 1분마다(탭이 보일 때), 탭으로 돌아올 때, 실행이 끝나거나 연결이 바뀔 때 읽는다.
- 사용량을 읽지 못해도 실행을 막지 않는다.

## 규칙

- **어댑터 형태**: CLI마다 어댑터를 두고 같은 형태로 맞춘다 — 입력 `{ prompt, sessionId? }`, 출력은 텍스트 조각 스트림(없을 수 있음)과 최종 `{ text, sessionId }`. 상태 확인과 로그인 실행도 어댑터가 맡는다.
- **프롬프트는 표준입력으로**: 명령 인자 길이 제한을 피하기 위해서다.
- **실행 환경**: 고정된 빈 작업 폴더에서 실행하고, API 키 환경변수를 지우고, 사용자 설정을 불러오지 않는다 ([1-SYSTEM-ARCHITECTURE.md](../1-SYSTEM-ARCHITECTURE.md#실행-환경)).
- **에이전트 권한**: 에이전트는 파일을 쓰지 않고 텍스트만 돌려준다. Claude는 도구가 없고, Codex는 읽기 명령만 실행할 수 있다.
- **저장소 프로젝트**: 작업 폴더를 그 프로젝트의 클론 폴더로 바꾼다. Claude는 `--tools Read,Grep,Glob --restricted --allowedTools Read,Grep,Glob`(기존 `--setting-sources ""`·`--strict-mcp-config` 유지), Codex는 `-c project_doc_max_bytes=0 -C <클론>`(read-only 유지)으로 실행해 저장소의 `AGENTS.md`를 읽지 않게 한다. 에이전트 자식 환경에서는 `GH_CONFIG_DIR`·`GIT_CONFIG_GLOBAL`을 지운다. 그 밖의 실행 환경 규칙은 같다 ([github.md](github.md#저장소-프로젝트의-생성)).
- **구독만 허용**: 구독이 아닌 방식(Claude `authMethod`가 `claude.ai`가 아님, Codex가 ChatGPT 로그인이 아님)으로 로그인돼 있으면 실행하지 않고 구독 로그인을 안내한다. 로그인 버튼도 구독 로그인만 실행한다 (Claude `--claudeai`).
- **인증 정보는 CLI만 다룬다**: 앱은 공식 CLI 로그인 명령을 실행할 뿐, 자체 OAuth를 구현하지 않는다. 토큰은 CLI가 자기 저장소에 보관하고, 앱은 읽거나 저장하지 않는다.
- **로그인 출력은 남기지 않는다**: 로그인 명령이 출력한 URL·코드는 화면에만 보여 주고 DB·로그에 남기지 않는다.
- **기존 반환 코드 API**: Claude 로그인 세션별 식별자를 확인한 뒤 열린 stdin으로 한 줄을 한 번만 전달한다. 이전·종료·취소 세션과 중복 제출은 거절한다. 입력은 가리고 전송 후 비우며 DB·서버 로그·콘솔 출력에 복사하지 않는다. 범용 셸 입력은 받지 않는다.
- **기존 한 줄 입력 API**: 두 CLI의 로그인 세션 식별자를 확인하고 한 줄씩 stdin에 전달한다. 콘솔 입력은 stdin을 닫지 않아 다음 입력을 받을 수 있다. 빈 Enter는 허용하고 4,096자를 넘는 값·개행·제어 문자는 거절한다. 종료·취소·이전 세션은 입력할 수 없다. Claude 간편 코드 제출 후에는 콘솔 입력도 닫는다. 앱은 입력을 출력에 복사하거나 저장하지 않는다.
- **터미널 입력**: 세션 식별자를 확인한 PTY에 raw 문자열을 전달한다. 제어 문자는 터미널 입력으로 허용하며 한 요청은 16,384자 이하다. 셸을 통하지 않고 고정된 로그인 명령에만 전달한다. 종료·취소·다른 세션의 입력은 거절한다. 입력과 출력은 서버 로그에 저장하지 않는다.
- **로그인 실행 수**: CLI마다 로그인은 한 번에 하나만 돈다. 진행 중 재요청은 409이며 화면에서 기존 연결을 종료할 수 있다. 취소 API의 204는 해당 프로세스 종료와 잠금 해제 후 반환한다. 로그인 생명주기 로그에는 agent·event·소요 시간·결과만 기록한다. 사용자가 취소하거나 10분이 지나면 로그인 프로세스를 종료한다.
- **연결 끊김**: 브라우저 연결이 끊기면 자식 프로세스(실행·로그인)를 종료하고 결과를 저장하지 않는다.
- **종료 정리**: 취소·시간 초과·서버 종료 시 CLI가 만든 하위 프로세스도 그룹 단위로 정리한다. 종료 신호를 무시하면 강제 종료한다 ([종료 처리](../1-SYSTEM-ARCHITECTURE.md#서버-공유-상태)).
- **잠금 해제 시점**: 실행이 끝나면 프로젝트 실행 잠금을 푼 뒤에 `done`·`error`를 보낸다. 화면 정의서는 `done`을 받자마자 브라우저가 저장하기 때문이다.
- **세션 ID 저장**: 첫 턴이 성공한 뒤에 저장한다. 첫 턴이 실패하면 다음 시도는 새 세션으로 시작한다.

## 예외

| 오류 코드 | 판정 | 화면 |
| --- | --- | --- |
| `cli_not_found` | 실행 파일을 찾지 못함 | 설치 안내와 `CLAUDE_CLI`/`CODEX_CLI` 설정 안내, 다른 에이전트 선택 가능 |
| `not_logged_in` | 상태 확인이 미로그인 | 별도 연결 화면 링크 |
| `not_subscription` | 구독이 아닌 방식으로 로그인됨 | 별도 연결 화면에서 구독 로그인 |
| `login_failed` | 로그인 명령이 실패·시간 초과·취소로 끝남 | 연결 화면에서 짧은 오류와 다시 시도 버튼 |
| `agent_failed` | 그 밖의 비정상 종료 (`is_error`, `turn.failed` 포함) | 에러 메시지와 다시 실행 버튼 |

## SSE 이벤트 (예정)

인터뷰·문서 생성·화면 주석 API가 공통으로 쓴다.

| 이벤트 | 데이터 | 의미 |
| --- | --- | --- |
| `delta` | `{ text }` | 출력 조각 (Claude만) |
| `done` | `{ text }` | 완료. 마크다운 문서·인터뷰는 서버가 저장한 최종 본문, 화면 정의서·화면 주석은 저장 전 응답 원문 |
| `error` | `{ code, message }` | 위 오류 코드 중 하나 |

로그인 API는 아래 이벤트를 쓴다.

| 이벤트 | 데이터 | 의미 |
| --- | --- | --- |
| `prompt` | `{ url, code? }` | 사용자가 열 URL (Codex는 입력할 코드 포함) |
| `output` | `{ text }` | 두 CLI의 raw PTY 출력(ANSI 포함). 개행 없는 프롬프트도 즉시 전달 |
| `input_ready` | `{ loginId }` | 두 CLI의 현재 stdin 입력 세션 식별자 |
| `done` | `{ loggedIn }` | 로그인 명령 종료 후 상태 확인 결과 |
| `error` | `{ code, message }` | `login_failed` 또는 `cli_not_found` |

## API (예정)

| 메서드·경로 | 응답 |
| --- | --- |
| `GET /api/agents` | `{ claude: { installed, loggedIn, subscription, loginCommand, loginRunning }, codex: { installed, loggedIn, subscription, loginCommand, loginRunning } }`. `loginCommand`는 터미널 로그인 안내 문구 |
| `GET /api/agents/usage` | `{ claude, codex }`, 각각 `{ fiveHour, weekly, readAt } \| null`(구독 로그인이 아니면 `null`). 한도는 `{ usedPercent, resetsAt } \| null`. `usedPercent`는 0–100 정수, `resetsAt`·`readAt`은 ISO 시각. CLI 확인이 실패해도 200 |
| `POST /api/agents/:agent/login` | `{ terminal: true }`로 PTY 로그인 시작. SSE `input_ready`·`output` → `done`/`error`. 본문이 없으면 이전 pipe 로그인 API 유지 |
| `PUT /api/agents/:agent/login` | `{ loginId, data }` raw PTY 입력 또는 `{ loginId, cols, rows }` resize(열 2–500, 행 2–200). 성공 204, 형식 오류 400, 종료·다른 세션 409 |
| `PUT /api/agents/:agent/login` | `{ loginId, input }`으로 로그인 CLI에 한 줄 전달 (빈 Enter 허용), 성공 204. 형식 오류 400, 종료·취소·다른 세션 409 `invalid_state` |
| `PUT /api/agents/claude/login` | `{ loginId, code }`를 받아 CLI stdin으로 전달, 성공 204. 형식 오류 400, 입력 불가·다른 세션·중복 제출 409 `invalid_state` |
| `DELETE /api/agents/:agent/login` | 진행 중인 로그인 취소 |
| `POST /api/agents/:agent/logout` | 공식 CLI로 SDDMaker 전용 로그인 해제. 성공 204, 인증 작업 진행 중 409, 실패 시 오류 표시와 재시도 |
