# 사용자 흐름

> 상태: 예정 — MVP 구현 전 ([changes/001-mvp.md](changes/001-mvp.md)).

## 진입점과 종료점

- **진입**: 터미널에서 `npm run dev` → 브라우저로 접속 → 프로젝트 목록. 앱 자체 계정 로그인은 없다.
- **종료**: 승인된 문서 세트를 zip으로 내려받는다. 이후 개발은 SDDMaker 밖에서 한다.

## 주요 여정

```text
프로젝트 목록
  └─ 새 프로젝트 (이름 + 아이디어 + 디자인 문서(선택))
       └─ 프로젝트 상세
            ├─ 인터뷰 ──(요약 승인)──┐
            └─ 인터뷰 건너뛰기 ─────┤
                                     ▼
            0-PRODUCT ──(승인: 기능 목록 확정)──► 1-SYSTEM-ARCHITECTURE ► 3-DATABASE ► 4-USERFLOW
                                     ▼
            requirements/<기능> × N  (순서 없음)
                                     ▼
            screens/<화면> × N  (순서 없음, 주석 모드로 컴포넌트 선택·그리기 수정)
                                     ▼
            changes/001-mvp
                                     ▼
            내보내기 (zip 다운로드)

  각 문서 단계: 생성 → 편집/피드백(되돌리기) → 승인
```

1. **프로젝트 생성** — 이름과 아이디어를 입력하고, 있으면 디자인 문서를 붙여 넣는다. → [requirements/project.md](requirements/project.md)
2. **인터뷰 (선택)** — 에이전트를 고르고 질문에 하나씩 답한다. 끝나면 요약을 편집·승인한다. 건너뛰면 아이디어만으로 시작한다. → [requirements/interview.md](requirements/interview.md)
3. **문서 단계** — 단계마다 에이전트를 고르고 생성한다. 직접 편집하거나 피드백으로 재생성하고, 마음에 안 들면 되돌린다. 승인하면 다음 단계가 열린다. `0-PRODUCT.md`를 승인할 때 만들 요구사항 문서 목록이 정해진다. → [requirements/documents.md](requirements/documents.md)
4. **내보내기** — 승인된 문서 세트를 `docs/` 구조의 zip으로 내려받는다. → [requirements/export.md](requirements/export.md)

## 화면 간 이동

- 프로젝트 목록 → 프로젝트 상세 (프로젝트 선택 또는 생성 직후)
- 프로젝트 상세 안에서는 단계 목록(인터뷰 · 고정 문서 · 요구사항 문서 목록 · 변경 기록 · 내보내기)으로 이동한다. 생성 조건이 안 되는 단계도 열 수는 있지만 생성 버튼이 비활성이다.
- 앱을 다시 켜면 프로젝트 목록에서 이어서 진행한다. 진행 상태는 DB에 남아 있다.

## 인증·권한 분기

앱 자체 인증은 없다. 분기는 에이전트 CLI의 설치·로그인 상태 하나다.

| 상태 | 화면 |
| --- | --- |
| 선택한 CLI가 설치·로그인됨 | 정상 실행 |
| CLI 미설치 | 설치 안내. 다른 에이전트를 고를 수 있다 |
| CLI 미로그인 | 로그인 버튼으로 앱에서 구독 로그인 (Claude는 브라우저 로그인, Codex는 URL·코드 입력). 터미널 로그인도 안내. 로그인 후 다시 실행 |

세부 판정 방법은 [requirements/agent-cli.md](requirements/agent-cli.md).

## 주요 실패·복구 경로

| 실패 | 복구 |
| --- | --- |
| 생성 도중 에이전트 실패·중단 | 기존 본문은 바뀌지 않는다. 에러를 보여 주고 다시 실행할 수 있다 |
| 피드백 재생성 결과가 나쁨 | 되돌리기로 직전 본문 복구 (1회분) |
| `0-PRODUCT.md`에 요구사항 링크가 없거나 규칙 위반 | 승인되지 않는다. 본문을 고치거나 피드백으로 재생성한 뒤 다시 승인 |
| 인터뷰 도중 앱 종료 | 메시지와 세션 ID가 남아 있어 이어서 답할 수 있다 |
