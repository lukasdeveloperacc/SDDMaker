# 019 토큰 CSS와 디자인 시스템 페이지

> 상태: 구현·자동 검증 완료 (2026-11-05). 실제 에이전트로 페이지를 만든 결과의 품질은 확인하지 않았다.

## 이유

Claude Design이 만드는 디자인 시스템 패키지는 토큰 CSS와, 색·글꼴·컴포넌트와 상태를 눈으로 보는 페이지를 함께 준다. SDDMaker는 글로 된 `2-DESIGN.md`만 있어서 화면을 하나씩 만들면 컴포넌트 모양이 화면마다 갈렸다. 디자인 문서를 견본 페이지로 만들고, 화면이 그 견본을 그대로 가져다 쓰게 한다.

## 범위

- 토큰 CSS(`src/lib/design-tokens.ts`): `2-DESIGN.md` YAML 머리말을 에이전트 없이 CSS 변수로 바꾼다. YAML은 `js-yaml`로 읽는다. 머리말이 없는 문서(getdesign.md 등)는 디자인 시스템 페이지가 정의한 `:root` 블록을 토큰으로 쓴다.
- 디자인 시스템 페이지: `POST /api/projects/:id/design/system`(서버 저장, `projects.design_html`), 디자인 단계의 미리보기·피드백 재생성.
- 화면 생성 입력에 토큰 CSS와 페이지를 넣는다.
- 내보내기·PR에 `docs/2-DESIGN.tokens.css`, `docs/2-DESIGN.html`을 넣는다. 문서 규칙(`docs/AGENTS.md`)에 두 파일을 더했다.

자세한 규칙은 [screens.md](../requirements/screens.md#토큰-css와-디자인-시스템-페이지).

## 제외 범위

- 이미지 에셋(앱 아이콘·파비콘·마스코트), 화면 PNG, 기기별(웹·모바일 웹·태블릿·iOS·Android) 화면 버전.
- 페이지의 승인·되돌리기, 디자인 문서가 바뀌었을 때 페이지 자동 갱신, impeccable live로 페이지 다듬기.

## 검증

- 단위: 토큰 변환(참조·camelCase·배열·위험 값 제거·머리말 없음).
- 서버: 디자인 문서 없음 409, 생성·저장, 피드백에 현재 페이지 포함, 스크립트 거부, 화면 프롬프트에 토큰·페이지 포함, 내보내기 파일 목록.
- 화면: 토큰 개수 표시, 생성 요청, 미리보기 iframe `sandbox=""`, 피드백 재생성.
- 전체 테스트 57파일·701개, 타입 검사, 린트 통과.
