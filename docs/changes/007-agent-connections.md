# 007 에이전트 연결 분리와 작업 화면 정리

> 상태: 완료

## 범위

프로젝트마다 반복되던 로그인 UI를 `/settings/agents`의 에이전트 연결 화면으로 옮긴다. 연결 화면은 간편 로그인과 실제 터미널을 탭으로 제공한다. 작업 화면에는 에이전트 Select만 남긴다. 기존 PTY·인증 저장소·로그인 취소와 충돌 복구 계약은 유지한다.

프로젝트 상세의 공통 디자인 문서 카드를 제거한다. 저장된 디자인 문서와 생성·내보내기 API는 보존한다. 디자인이 없어 화면 생성이 막힌 경우에만 해당 단계에 입력란을 제공한다. 기존 디자인 시스템의 색·타이포·간격으로 작업 영역과 단계 내비게이션을 정리하며, 작은 화면에서는 단계 Select를 사용한다.

## 작업과 검증

- 기존 로그인 회귀 테스트를 연결 화면으로 옮기고, 간편 로그인·터미널 탭·코드 전송·충돌 복구를 검증한다.
- 작업 화면의 Select 변경·잠금과 로그인 UI 부재를 검증한다.
- 린트·타입 검사·테스트·Docker 빌드를 수행한다.
- 실제 브라우저에서 데스크톱·모바일의 연결 화면과 프로젝트 화면, 탭과 Select를 확인한다.
- 실제 계정의 인증 완료는 사용자의 브라우저 동작이 필요하므로 별도로 구분한다.

## 결과

- 26개 파일의 317개 테스트, 전체 린트·타입 검사, Docker 빌드를 통과했다. 독립 소스 리뷰에서 필수 수정 사항이 없었다.
- 1122px와 390px 브라우저에서 프로젝트 작업면·단계 전환·에이전트 Select·연결 탭을 확인했다. 단계 목록의 가로 잘림을 수정하고 재확인했다.
- 가짜 CLI를 사용한 브라우저 검증에서 Claude 간편 코드 전송(204), Codex 인증 URL·코드 표시, 실제 PTY 터미널의 키 입력과 취소를 확인했다. 디자인이 없는 화면 단계에서만 입력하고 저장 후 생성 조건이 갱신되는 것도 확인했다.
- 격리된 임시 Docker 컨테이너에서 실제 Claude/Codex CLI 각각의 간편 로그인 URL/코드 안내와 PTY 안내, 종료 후 세션 해제를 확인했다. 인증 값은 로그에 출력하지 않았다.
- 최종 Compose 컨테이너가 healthy이며 `/projects/1`과 `/settings/agents`가 200을 반환한다. 실제 계정의 인증 완료와 인증 후 모델 실행은 검증하지 않았다.
