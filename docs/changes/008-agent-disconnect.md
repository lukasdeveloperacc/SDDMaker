# 008 에이전트 연결 해제

> 상태: 완료

## 범위

에이전트 연결 화면에서 로그인된 Claude Code·Codex 각각에 연결 해제를 제공한다. 공식 CLI 로그아웃을 SDDMaker 전용 인증 환경에서 실행하며 호스트 로그인과 프로젝트·문서는 건드리지 않는다. 진행 중 로그인 취소는 기존 동작으로 유지한다. 같은 CLI의 로그인과 로그아웃은 직렬로 실행한다.

관련 기준: [에이전트 연동](../requirements/agent-cli.md), [사용자 흐름](../4-USERFLOW.md).

## 검증

두 CLI의 로그아웃 명령·실패 처리·인증 잠금 해제와 화면 상태 갱신·중복 조작 방지를 회귀 테스트한다. 린트·타입 검사·전체 테스트·Docker 빌드 후 배포 상태를 확인한다. 실제 사용자 계정은 검증 과정에서 로그아웃하지 않는다.

## 결과

- 공식 로그아웃 후 상태까지 확인하며, 실패·중복·취소·시간 초과는 오류로 처리하고 잠금을 해제한다. 설정·문서를 삭제하지 않는다.
- 전체 회귀 테스트와 린트·타입 검사, Docker 프로덕션 빌드를 통과했다.
- 브라우저 1122px·390px에서 계정별 버튼과 상태 갱신, 오류 후 재시도, 가로 넘침이 없는 것을 확인했다. 이 검증의 인증 API는 모의 응답을 사용했다.
- 호스트 볼륨을 연결하지 않은 임시 컨테이너에서 실제 Claude·Codex CLI의 로그아웃 API가 각각 204를 반환하고 미로그인·잠금 해제 상태가 되는 것을 확인했다. 임시 컨테이너는 종료했다.
- 기본 Compose 컨테이너를 새 이미지로 갱신했고 healthy를 확인했다. 실제 로그인 계정의 토큰 해제는 사용자 계정을 보존하기 위해 실행하지 않았다.
