# 001 MVP

> 상태: 예정

## 변경 이유

앱을 만들 때마다 SDD 문서를 먼저 만들고, 그 문서로 Agentic 개발을 하기 위한 도구가 필요하다. 이미 쓰고 있는 Claude·OpenAI 구독을 API 키 없이 활용한다.

요구사항은 2026-10-19 인터뷰(11라운드)로 확정했다. 생성할 문서 세트는 인터뷰에서 정한 4종(PRD · 아키텍처 · 데이터·API · 태스크) 대신, 같은 날 SDDMaker 자신의 [docs 규칙](../AGENTS.md) 구조로 바꿨다. 한 번 쓰고 끝나는 문서가 아니라 MVP 이후에도 같은 규칙으로 갱신되는 문서를 만들기 위해서다.

같은 날 화면 정의서(`screens/<화면>.html`)를 MVP에 넣고 docs 규칙에 `screens/`를 추가했다. 텍스트 요구사항만으로는 코딩 에이전트가 화면 배치를 추측하기 때문이다. 수정 방식은 Orca 내장 브라우저처럼 컴포넌트를 고르거나 그림을 그려 주석을 쌓고, 템플릿으로 묶어 에이전트에게 보낸다.

## 구현 작업

1. **CLI 확인 (먼저)**: 설치된 `claude`, `codex`로 비대화 실행·JSON 스트림·세션 이어하기·도구 제한 플래그, 로그인 상태 확인 출력, 그리고 두 로그인 명령(`claude auth login --claudeai`, `codex login --device-auth`)이 터미널 없는 자식 프로세스에서 URL·코드를 어떻게 내는지 실제로 확인하고, [1-SYSTEM-ARCHITECTURE.md](../1-SYSTEM-ARCHITECTURE.md)에 기록한다. 두 CLI의 형식이 달라 가장 큰 위험이다.
2. Next.js(TypeScript) 프로젝트 생성, `npm run dev` 확인.
3. SQLite 스키마와 DB 모듈 ([3-DATABASE.md](../3-DATABASE.md)).
4. 에이전트 어댑터 2개(실행·상태 확인·로그인)와 SSE 응답 공통 처리 ([requirements/agent-cli.md](../requirements/agent-cli.md)).
5. 프로젝트 API·화면 (디자인 문서 입력 포함).
6. 인터뷰 API·화면.
7. 문서 API·화면 — 편집기, 피드백, 되돌리기, 승인, 생성 순서 검사, `0-PRODUCT.md` 승인 시 기능 목록 확정.
8. 화면 정의서 — `4-USERFLOW.md` 승인 시 화면 목록 확정, iframe 미리보기, 선택·그리기 주석과 주석 목록, 요청 템플릿, 응답 블록 반영·정리.
9. 문서 종류별 프롬프트, 화면 주석 템플릿, 문서 규칙(`AGENTS.md`) 사본.
10. zip 내보내기.
11. 아래 검증 시나리오 수행 후 문서를 실제 상태로 갱신하고 `예정` 표시를 제거한다.

## 검증 방법

각 요구사항 문서의 완료·테스트 기준을 모두 통과하고, 아래 시나리오가 처음부터 끝까지 동작해야 한다.

1. `npm run dev`로 실행 후 브라우저 접속
2. 새 프로젝트 생성, 아이디어와 디자인 문서 입력
3. Claude로 인터뷰 → 완료 → 요약 수정·승인
4. Codex로 `0-PRODUCT.md` 생성 → 직접 수정 → 피드백 재생성 → 되돌리기 → 다시 재생성 → 승인 → 요구사항 문서 목록 확인
5. 단계마다 에이전트를 바꿔 가며 `1` → `3` → `4`(화면 목록 확인) → 요구사항 문서 전부 승인
6. 화면 정의서 하나에서 컴포넌트 수정 주석 2개 + 그림 주석 1개 + 질문 1개를 쌓아 한 번에 보내기 → 해당 컴포넌트만 바뀌고 질문 답이 보이는지 확인 → 되돌리기 → 다시 보내고 승인. 나머지 화면도 승인
7. `changes/001-mvp.md` 승인
8. zip 다운로드, `docs/` 구조와 `AGENTS.md` · `2-DESIGN.md` · `screens/` 포함 확인
9. 앱 재시작 후 프로젝트·문서·상태 유지 확인
10. 두 CLI를 각각 로그아웃 → 앱의 로그인 버튼으로 구독 로그인 → 상태가 로그인됨으로 바뀌고 생성이 되는지 확인
11. 별도 프로젝트에서 인터뷰 건너뛰기 → `0-PRODUCT.md` 생성 확인

## 결정 필요 (구현 전)

정해지면 관련 요구사항 문서에 반영한다.

- 승인된 문서를 다시 편집·재생성할 수 있는가? 가능하다면 상태를 `draft`로 되돌리는가, 뒤 문서들은 어떻게 되는가? (`0-PRODUCT.md`를 다시 승인하면 요구사항 문서 목록도 바뀐다)
- 인터뷰를 시작한 뒤에도 건너뛸 수 있는가? (현재 문서: 시작 전에만)
- 프로젝트 삭제를 MVP에 넣는가?
- 그리기 주석에 그림 이미지(미리보기 캡처 + 그린 선)도 첨부하는가? 현재 문서는 영역 좌표와 겹치는 컴포넌트만 텍스트로 보낸다. 첨부하려면 두 CLI의 비대화 실행 이미지 입력 방법과 iframe 캡처 방법을 먼저 확인해야 한다.
